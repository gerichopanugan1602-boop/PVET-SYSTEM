1. Install and start XAMPP.
   Install XAMPP, then open its Control Panel and start Apache and MySQL. Both should turn green.
   Open http://localhost/ and confirm that the XAMPP welcome page appears.
2. Copy the project into XAMPP.
   Copy the complete pigerry folder into:
   C:\xampp\htdocs\pigerry
   The folder should directly contain:
   pigerry
   ├── assets
   ├── config
   ├── includes
   ├── ml
   ├── assessment.php
   ├── dashboard.php
   ├── home.php
   ├── login.php
   ├── records.php
   └── reset_admin.php
   Keep all other project files too. If reset_admin.php was already deleted from your working installation, get it from your original project package for this setup.
   Open http://localhost/pigerry/home.php to confirm the website loads.
3. Create the database and administrator table.
   In XAMPP, click Admin beside MySQL to open phpMyAdmin.
   Click the SQL tab, paste the following, and click Go:
   CREATE DATABASE IF NOT EXISTS swine_farmer_services
       CHARACTER SET utf8mb4
       COLLATE utf8mb4_unicode_ci;
   
   USE swine_farmer_services;
   
   CREATE TABLE IF NOT EXISTS admins (
       id INT UNSIGNED NOT NULL AUTO_INCREMENT,
       username VARCHAR(50) NOT NULL,
       password_hash VARCHAR(255) NOT NULL,
       created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
       PRIMARY KEY (id),
       UNIQUE KEY unique_username (username)
   ) ENGINE=InnoDB
     DEFAULT CHARSET=utf8mb4
     COLLATE=utf8mb4_unicode_ci;
   An “empty result set” success message is normal.
   The project creates its assessments table automatically when it connects through its database helper.
4. Check the database configuration.
   Open:
   C:\xampp\htdocs\pigerry\config\database.php
   Our working setup used these XAMPP defaults:
   const DB_HOST = '127.0.0.1';
   const DB_PORT = 3306;
   const DB_NAME = 'swine_farmer_services';
   const DB_USER = 'root';
   const DB_PASS = '';
   If the other laptop uses a different database port or password, adjust those values.
5. Create the administrator account.
   Open the copied file:
   C:\xampp\htdocs\pigerry\reset_admin.php
   Find:
   $username = 'admin';
   $password = 'ChangeMe123!';
   Replace the password with your own. Keep the quotes and semicolons; avoid single quotes and backslashes in the password text for this step.
   Save, then open:
   http://localhost/pigerry/reset_admin.php
   Confirm that the message contains CREATED and Verified OK.
   Delete reset_admin.php from the served project folder afterward, because it can reset administrator passwords.
   Open http://localhost/pigerry/login.php and check that you can sign in.
6. Install Python 3.10 and the model’s packages.
   Use Python 3.10 to match the working setup. Your laptop used 3.10.6.
   Open Command Prompt and check:
   py -3.10 --version
   py -3.10 -m pip --version
   Create a separate environment:
   py -3.10 -m venv "%USERPROFILE%\pigerry-venv"
   Install the versions used successfully:
   "%USERPROFILE%\pigerry-venv\Scripts\python.exe" -m pip install "numpy==1.26.4" "scikit-learn==1.1.3"
   Verify:
   "%USERPROFILE%\pigerry-venv\Scripts\python.exe" -c "import numpy, sklearn; print('NumPy:', numpy.__version__); print('scikit-learn:', sklearn.__version__)"
   Expected output:
   NumPy: 1.26.4
   scikit-learn: 1.1.3
7. Connect PHP to the new laptop’s Python environment.
   Open:
   C:\xampp\htdocs\pigerry\ml\cluster.php
   Update the PYTHON_CMD line. On your current laptop, it is:
   const PYTHON_CMD = 'C:\\Users\\ASUS\\pigerry-venv\\Scripts\\python.exe';
   On another laptop, replace ASUS with that laptop’s Windows user folder name. Running this in Command Prompt shows the correct user folder:
   echo %USERPROFILE%
   Save the file.
8. Test the complete flow.
   - Sign in successfully.
   - Open http://localhost/pigerry/assessment.php.
   - Submit an assessment using sample answers.
   - Confirm recommendations appear.
   - Open http://localhost/pigerry/records.php and find the assessment.
   - Open http://localhost/pigerry/dashboard.php and confirm the records and totals reflect it.
9. Use the system afterward.
   Each time, start Apache and MySQL in XAMPP, then visit:
   http://localhost/pigerry/home.php
   Make future code changes inside C:\xampp\htdocs\pigerry, since that is the copy Apache serves.
Existing records are stored in MySQL and won’t transfer by copying the project folder; transferring them also requires a database export/import.
